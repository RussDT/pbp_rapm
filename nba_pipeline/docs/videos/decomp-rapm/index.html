Decomp RAPM

A point-value decomposition of where a player changes team scoring margin while on the floor.

top level
RAPM = ORAPM + DRAPM
Output: offense, defense, and net impact in the same public sign convention. Read as: a structure for team outcome shifts, not a box-score stat.
OFF
offensive side

ORAPM opens into three channels.

ORAPM = oTS + oTOV + oSC + residual
scoring

oTS

First-chance scoring value: shots and free throws before the first offensive miss.

control

oTOV

Point value kept or lost when a possession turns over before first-chance scoring completes.

extra chance

oSC

Second-chance scoring after the offense creates another life with a miss recovery.

Shared frame: the public display is an accounting map around first chance plus second chance. Residual: expected to be small, mostly rounding and assembly gap.
SHOT
first-chance scoring

The scoring branch drills down without changing the denominator.

oTS = oEFG + oFT
oEFG = baseline + rim + mid + three
rimfrequency value + within-zone make value
midfrequency value + within-zone make value
threefrequency value + within-zone make value
free throwstrip frequency + trip severity
Shot value: mix and make are separated so location and conversion do not blur together. FT value: trips and trip quality are distinct pieces of first-chance offense.
DEF
defensive mirror

DRAPM uses the same map from the other side.

Defensive components are sign-flipped for display, so positive means good defense.

defensive total
DRAPM = dTS + dTOV + dSC
channel

good defense means
dTS

Creating disruption without paying it back elsewhere.
dSC
Second-chance points after the first offensive miss.
Ending possessions or deflating putback value.
