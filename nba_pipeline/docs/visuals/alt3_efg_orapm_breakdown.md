# Alt3 EFG oRAPM Breakdown Infographic

This folder contains a clean one-page visual explanation of the Alt3 EFG-value offensive weighted-factors breakdown.

Files:

- `alt3_efg_orapm_breakdown.svg` - editable source.
- `alt3_efg_orapm_breakdown.png` - rendered image for sharing.
- `alt3_efg_orapm_breakdown_philosophy.md` - design note used to guide the visual.

Core explanation represented in the graphic:

- `oRAPM = oFC + oSC`
- `oFC = oALT_EFG_VALUE + oALT_TOV_VALUE + oALT_FT`
- `oALT_EFG_VALUE` breaks into rim/mid/three frequency and FG impact atoms.
- `oALT_TOV_VALUE` breaks into bad-pass and scoring turnover value, with live/dead-ball noted as a diagnostic lens.
- `oALT_FT` breaks into FT trip frequency and trip severity; severity includes trip type mix plus FT shooting.
