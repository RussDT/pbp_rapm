# Blocked-shot rate for rim percentage

September 14, 2026: owner-requested single-feature incremental experiment. Existing panel already has rim_pct and mid_pct (all non-rim twos), but no independent combined two_pct filter. Derived 2P% can be formed from their expected makes divided by summed predicted attempts; it is a composition, not a separately validated model. Rim classification is the canonical PBP layup/dunk/tip/action taxonomy, not a strict distance boundary.

Feature: strictly earlier BLKA / FGA, where BLKA counts the shooter's attempts blocked, not blocks credited to the defender. All-shot denominator, not rim-specific. Join exact ID/date/season/phase with AST/FGA/minutes agreement; missing BLKA rows advance neither numerator nor denominator. Initialize with 100 attempts at the 2019 observed rate. Controls already include pregame rim Kalman estimate/variance, prior rim attempts/100, FT% and cumulative rim attempts. Add only blocked share to standardized residual ridge alpha1000. Base Kalman grid selected on 2019 only, models trained on seasons2020 through S−1; dev2021–22, historical spent stress2023–25. 2026 is not scored; 2027 untouched. Fixed one-SE logloss improvement plus joint rim FGM/100 noninferiority gate. Report rejected candidates diagnostically without retuning. Both variants use the same pregame rim volume prediction, and zero-rim-attempt games enter joint loss.

Run `nba_pipeline/scripts/research_rim_blocked_prior.py`. Research outputs in ignored `results/estimated_skills/rim_blocked_prior/`. Bootstrap helper calls the generic fields three_fgm/three_fga internally after replacing them with rim counts; every metric here concerns rim shots. No table replacement or EPM comparison implied. The derived current 2P% CSV uses existing saved states (which can have different observation dates), not the experimental blocked-shot model.
