# Physical features for predictive statistics

Owner request September14,2026. `estimated_skills_physical.py` provides an exact nba_id join from Databallr measurements_master, cached locally as ignored nba_pipeline/cache/measurements_master.json. Export current candidate features with `.venv/bin/python nba_pipeline/scripts/estimated_skills_physical.py`.

Features, in inches: height without shoes, wingspan, wingspan minus height; explicit missing flags and measurement-source player name. 509/582 archive-current players have all three;73 remain missing. Do not substitute listed height for no-shoes height silently, invent wingspans, use source defensive impact columns, or attach numerical credit merely for size. The derived span difference is exactly redundant with the two raw features; regularization is necessary and individual coefficients should not be interpreted independently.

The source has no measurement timestamps. Historical availability is unverified for every row. Adapter fails unless callers explicitly allow undated current/retrospective use; physical snapshots are not silently treated as historically known. This is suitable for new forecasts after retrieval, but historical use must be labeled retrospective or supported by separately dated measurements. The earlier VPM rejection concerned direct player-prior features, not every predictive-stat task or lineup interaction.

The shooting fusion runner now accepts `--physical-features --allow-undated-measurements`. It adds the physical features only to linear and boosted second stages, with explicit missing flags and median imputation fitted within each training fold. Unchanged controls remain the same independent/decay/volume/FT models. Output is isolated at `results/estimated_skills/shooting_fusion_physical_retrospective/`; original outputs and current table are preserved. This is a first application of the reusable adapter; the opponent guard/wing/big rebounding model has not been built yet, so no claim of physical features improving it is warranted.

Verification: explicit undated-use guard, exact ID join, missing preservation, span subtraction, and existing prediction timing tests (5 pass). Current CSV includes provenance. Generated measurements and model artifacts stay untracked. Raw measurement dates and historical revisions remain a limitation even if a historical predictive screen improves.

First shooting screen completed: physical-feature linear1000 improves conditional logloss over the simple volume+FT control by0.02364% in development, but worsens joint3PM/100 MSE by0.09190%, failing the pre-existing gate. Final selection remains volume+FT, so physical features are available to candidate models but not admitted to the displayed shooting estimate. This result does not evaluate their value for rebounds, blocks or lineup-size interactions.
