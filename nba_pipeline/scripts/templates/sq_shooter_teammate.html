Own shots & teammate shots

Separating expected scoring value from conversion above expectation, for 2023–24 through 2025–26. SQ includes the shooter’s ability as well as the look. All four contributions are adjusted for offensive and defensive lineups.

Own SQ

Expected scoring value when the player takes the shot.

Teammate SQ

Expected scoring value when one of the other four players shoots.

Own shotmaking

The player’s conversion above or below talent-aware expectation.

Teammate shotmaking

Teammates’ conversion above or below that expectation.

How to read this

In the default view, units are points per 100 on-court team field-goal attempts, relative to average. Own SQ + teammate SQ = SQ parent; own shotmaking + teammate shotmaking = residual parent. The four sum exactly to the combined shot-impact estimate. This is field-goal shooting impact, not total offense: free throws, turnovers and rebound continuation are excluded.

The conditional view shows rates per 100 own-shot or teammate-shot opportunities. Multiply own rates by shot share and teammate rates by one minus shot share to recover the contributions. Conditional rates do not add directly. High usage can move difficult attempts onto the focal player while leaving easier attempts to teammates; the split retains that pattern.

Teammate impact can reflect passing, spacing, gravity, screening, lineup selection and other shared context. It does not identify those mechanisms separately. No external gravity values were supplied or joined.

Source coverage and model choices

The improved version uses saved season-forward context + EPM shooter skill + defender geometry + prior-game defender-identity predictions for matched 2024–25 and 2025–26 midrange shots and threes. Provider initial EV supplies 2023–24, rim shots and remaining unmatched shots. This is explicitly a mixed-source estimate. The consistent provider version is the three-year comparison control.

Geometry availability indicates whether an explicit closest-defender distance was present in the source; it does not certify which features the provider used internally. Missing EV, conflicting event keys, shooter mismatches and invalid lineups are excluded rather than filled. Regular-season status comes from the canonical RS shot files because the SQ archive’s playoff flag is unreliable for earlier seasons.

Each model jointly fits offensive players, defensive players, and a player-season-centered shooter interaction. Parent penalties are 3,000 offense / 5,000 defense. The shooter-role penalty is chosen separately for SQ and residual using three held-out game folds and a paired one-standard-error rule; annual estimates reuse pooled penalties. Season means are removed, all years receive equal per-shot weight, and there are no box priors or time decay. These settings produce a descriptive research split, not a newly validated predictive metric.

Positive means higher scoring value. Small samples remain uncertain; rankings are not confidence intervals. Prepared September 18, 2026.
