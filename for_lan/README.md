# For Lan

A single-file web page (`index.html`) with no build step and no dependencies beyond Google Fonts.

Open `index.html` in any browser, or publish the folder to any static host. Everything is drawn with raw WebGL: a scroll-driven flight through a procedural nebula and star field, seven 3D flowers that bloom as you fly past them (one per day of the week), comets, and a tap-to-burst interaction. It ends on a rotating ring of blooms around "Have a great week, Lan."
