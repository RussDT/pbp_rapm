# Project Commands Guide

This guide documents the essential commands for updating data and running RAPM analysis for both WNBA (primary focus) and NBA workflows.

## WNBA Workflow

### 1. Fetch Data
Use the CDN fetcher for current WNBA play-by-play. The old stats API fetcher can
disconnect for WNBA games; the CDN path scans static liveData ids and writes the
same raw CSV shape.

**Command Structure:**
```bash
python wnba_test/fetch_wnba_cdn.py --season <YEAR> --season-type "<TYPE>" --update-player-map
```

**Examples:**
- **2026 Regular Season:**
  ```bash
  python wnba_test/fetch_wnba_cdn.py --season 2026 --season-type "Regular Season" --update-player-map
  ```
- **Explicit game smoke test:**
  ```bash
  python wnba_test/fetch_wnba_cdn.py 1022600001 --output /tmp/WNBA26_smoke.csv
  ```

**Output:**
- Files are saved to `wnba_test/` (e.g., `wnba_test/WNBA25.csv`, `wnba_test/WNBA25_PS.csv`).
- `--update-player-map` appends new WNBA boxscore names to `wnba_test/player_index_map.csv` so RAPM outputs do not show `ID_<player_id>` for new players.

---

### 2. Process RAPM Input
Use `process_rapm_wnba.py` to process the raw PBP data into the four required input files (RAPM, TS, TOV, REB).

**Command Structure:**
```bash
python wnba_test/process_rapm_wnba.py <INPUT_FILE_PATH>
```

**Examples:**
- **Process 2025 Regular Season:**
  ```bash
  python wnba_test/process_rapm_wnba.py wnba_test/WNBA25.csv
  ```
- **Process 2026 Regular Season:**
  ```bash
  python wnba_test/process_rapm_wnba.py wnba_test/WNBA26.csv
  ```
- **Process 2025 Playoffs:**
  ```bash
  python wnba_test/process_rapm_wnba.py wnba_test/WNBA25_PS.csv
  ```

**Output:**
- Processed files are saved to `wnba_test/Processed/`.
- Generates 4 files per input: `RAPM{YY}.csv`, `TS{YY}.csv`, `TOV{YY}.csv`, `REB{YY}.csv`.

---

### 3. Run Master RAPM Analysis
Use `master_wnba_rapm.py` to run the regression analysis, calculate RAPM, and generate weighted factors.

**Command Structure:**
```bash
python wnba_test/master_wnba_rapm.py <START_YEAR> <END_YEAR> <SEASON_TYPE>
```
*Note: Years should be 2-digit format (e.g., 21 for 2021).*

**Examples:**
- **Run analysis for 2021-2025 (All Games):**
  ```bash
  python wnba_test/master_wnba_rapm.py 21 25 ALL
  ```
- **Run analysis for 2023-2025 (Regular Season only):**
  ```bash
  python wnba_test/master_wnba_rapm.py 23 25 RS
  ```

**Output:**
- Results are saved to `wnba_test/Results/rapm_{start}_{end}_{type}/`.
- Key file: `weighted_factors.csv` (contains Final RAPM, Residuals, and component breakdown).

---

## NBA Workflow

### 1. Fetch Data (V3)
Use `fetch_pbp_v3.py` to download NBA play-by-play data.

**Command Structure:**
```bash
python pbp_v3/fetch_pbp_v3.py --season <SEASON_STR>
```

**Examples:**
- **2025-26 Season:**
  ```bash
  python pbp_v3/fetch_pbp_v3.py --season 2025-26
  ```

---

### 2. Run Pipeline (NBA)
The `run_v3_pipeline.py` script typically handles the end-to-end process for NBA data, or you can use `rapm_pipeline.sh`.

**Example:**
```bash
python pbp_v3/run_v3_pipeline.py
```
*or*
```bash
./rapm_pipeline.sh
```

## Directory Structure Overview

- **`wnba_test/`**: Contains all WNBA-specific scripts and data.
  - **`Processed/`**: Intermediate files generated by `process_rapm_wnba.py`.
  - **`Results/`**: Final analysis output from `master_wnba_rapm.py`.
- **`pbp_v3/`**: Contains NBA V3 fetching scripts.
- **`Processed/`**: Default output folder for NBA processing.
